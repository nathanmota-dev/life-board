Tudo num só lugar

Um app no lugar de vários

Cada parte da sua rotina tem uma tela própria, e todas conversam entre si: uma tarefa entra numa meta, um evento aparece no painel, uma ideia vira tarefa.

  • Painel

    Seu dia de relance: agenda, foco, hábitos, humor e metas em widgets que você organiza.

  • Tarefas

    Tudo que você precisa fazer, organizado por prazo, com prioridade, etiquetas e visão em quadro ou lista.

  • Calendário

    Sua semana em um só lugar, com sincronização nos dois sentidos com o Google Agenda.

  • Metas

    Metas de curto e longo prazo divididas em etapas, com tarefas e hábitos vinculados.

  • Hábitos

    Beber água, ler, arrumar a casa: um emoji, uma meta diária e o histórico de constância.

  • Projetos

    Ideias e projetos em um quadro. Arraste um cartão para outra coluna para mudar o status.

  • Caixa de entrada

    Capture primeiro, organize depois. Um atalho global abre a captura rápida de qualquer lugar.

  • Ideias

    Ideias, anotações e tudo que vale lembrar, em cartões que você fixa e liga a tarefas.

  • GitHub

    Pull requests e issues para acompanhar, além das suas contribuições.

  • Pomodoro

    Ciclos de foco e pausa, com relógio e clima numa barra de status.

  • Páginas

    Páginas em Markdown com editor formatado, organizadas em pastas.

  • Arquivos

    Recibos, fotos e documentos organizados em pastas, com pré-visualização.

  • Humor

    Um registro diário de como você está se sentindo, com uma nota sobre o dia.

  • Atividade

    O que você tem feito ultimamente, num só histórico.

  • Etiquetas

    Tudo que você etiquetou em tarefas e ideias, reunido por etiqueta.

  • Busca rápida

    Pressione Ctrl K para encontrar qualquer página ou comando sem tirar a mão do teclado.

            Privacidade

            Seus dados ficam no seu computador

            O Life Board não tem servidor nem conta. O app roda inteiro na sua máquina e só se conecta a serviços que você mesmo ativa.

            Armazenamento local

            Tarefas, metas, hábitos, páginas e arquivos ficam num banco SQLite em ~/.config/life-board-app.

            Credenciais cifradas

            Tokens do GitHub e do Google são cifrados com AES-256-GCM, com a chave protegida pelo chaveiro do sistema.

            Sem rastreamento

            Sem anúncios, sem análise de uso e sem telemetria. O código é aberto, sob licença MIT.

            Instalar

            Instale no Linux em um minuto

            O Life Board é distribuído para Linux x64 em dois formatos, com o mesmo app e os mesmos dados. Os comandos abaixo já usam a versão mais recente.

            1. Baixe o pacote

              Arquivo life-board_<versão>_amd64.deb

              Baixar .deb

            2. Instale com o APT, na pasta do download

              $ cd ~/Downloads
sudo apt install ./life-board_*_amd64.deb

              O ./ é necessário: ele indica um arquivo local e faz o APT instalar também as dependências.

            3. Abra o Life Board

              Procure por Life Board no menu de aplicativos. Não é preciso instalar Node.js, npm ou Git.

            Ou baixe e instale num comando só

            $ cd /tmp && wget -O life-board.deb https://github.com/nathanmota-dev/life-board/releases/latest && sudo apt install ./life-board.deb

            1. Baixe o AppImage

              Arquivo life-board-<versão>-x86_64.AppImage

              Baixar AppImage

            2. Guarde num caminho fixo

              $ cd ~/Downloads
install -Dm755 life-board-*-x86_64.AppImage "$HOME/.local/opt/life-board/life-board.AppImage"

              Um caminho fixo mantém as atualizações pelo app e a inicialização com o sistema funcionando.

            3. Abra o app

              $ "$HOME/.local/opt/life-board/life-board.AppImage" --no-sandbox --no-zygote

              O AppImage requer FUSE (no Ubuntu 22.04 ou superior, o pacote libfuse2 ou libfuse2t64) e não cria atalho no menu.

            Requisitos

            • Linux x64: Debian, Ubuntu ou derivado. Testado no Ubuntu 22.04, 24.04 e 26.04 e no Debian 12 e 13.
            • Um chaveiro do sistema desbloqueado, como o GNOME Keyring ou o KWallet.
            • Sem pacotes oficiais para Windows, macOS, ARM, Snap, Flatpak ou RPM por enquanto.

            Atualizações

            O app procura versões novas uma vez por dia. Em Configurações → Atualizações, você escolhe quando baixar e instalar. Seus dados são mantidos.

            Para remover: sudo apt remove life-board. Os seus dados não são apagados.

            Guia completo

            Migração, cópia de segurança dos dados, atalho para o AppImage e instalação a partir do código.
