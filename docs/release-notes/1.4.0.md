O Life Board 1.4.0 traz a tela **Páginas**, para escrever e organizar notas em
Markdown em pastas, como num caderno. A distribuição continua sendo Linux x64, em
DEB e AppImage.

## Novidades

### Páginas

- A nova tela **Páginas**, no menu antes de **Arquivos**, mostra uma árvore de
  pastas e páginas à esquerda e a página aberta à direita. Em telas estreitas, a
  árvore abre num painel lateral.
- Crie páginas e pastas, renomeie com `F2` ou clique duplo, reorganize arrastando
  ou com **Mover para…** e exclua com confirmação. Uma pasta mostra quantas páginas
  serão excluídas junto com ela. **Recolher tudo** fecha as pastas abertas.
- A página abre em modo de leitura, com tabelas, listas de tarefas e tachado.
  **Editar** (ou `Ctrl+E`) abre o editor formatado ou o Markdown puro, e
  **Concluir** (ou `Esc`) volta à leitura. As mudanças são salvas sozinhas
  enquanto você digita, com `Ctrl+S` e ao trocar de página.
- **Importar .md** e **Importar pasta** trazem suas notas `.md` e `.markdown`,
  mantendo a estrutura de pastas. **Baixar .md** salva a página como está guardada.
- O HTML dentro de uma nota aparece como texto e nunca é executado, então notas
  importadas são seguras de abrir.

### Arquivos

- **Arquivos** não cria mais documentos: os documentos Markdown passam a ficar em
  **Páginas**. Um `.md` enviado para Arquivos abre no editor de texto simples.
- Em **Configurações → Arquivos**, a pasta das páginas aparece junto com a dos
  envios. Trocar a pasta move os envios e as páginas existentes.

## Instalação e atualização

Instale o DEB baixado da release com:

```bash
sudo apt install ./life-board_1.4.0_amd64.deb
```

O AppImage também está disponível. Instalações existentes podem atualizar em
**Configurações → Atualizações**, após a publicação desta versão.

Esta versão adiciona uma migration ao banco local, com a tabela das páginas.
Perfis existentes são migrados ao abrir e mantêm seus dados. Windows e macOS
continuam sem instaladores oficiais.

Veja o [guia de instalação no Linux](../instalacao-linux.md).
