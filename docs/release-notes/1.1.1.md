O Life Board 1.1.1 corrige a verificação dos arquivos públicos após a publicação
da release. A distribuição continua sendo Linux x64, em DEB e AppImage.

## Correção

- Os downloads de conferência agora usam uma pasta temporária exclusiva, evitando
  a colisão com a pasta `public/i18n` do código-fonte.
- Permanecem as verificações de conteúdo, checksums e feed de atualização; a
  pasta temporária é removida ao terminar, inclusive em caso de falha.
- Testes de regressão cobrem a pasta existente, um pacote alterado e um feed
  desatualizado.

## Instalação e atualização

Instale o DEB baixado da release com:

```bash
sudo apt install ./life-board_1.1.1_amd64.deb
```

O AppImage também está disponível. Instalações existentes podem atualizar em
**Configurações → Atualizações**, após a publicação desta versão.

Esta correção é no processo de release e não altera funcionalidades nem o formato
dos dados do aplicativo. A release 1.1.0 já publicada permanece intacta.
Windows e macOS continuam sem instaladores oficiais.

Veja o [guia de instalação no Linux](../instalacao-linux.md).
