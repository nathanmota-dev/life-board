O Life Board 1.1.0 é distribuído para Linux x64 (DEB e AppImage) e permite
escolher onde guardar os arquivos enviados. O código mantém adaptações para
Windows e macOS, sem instaladores oficiais para essas plataformas.
Os dados continuam armazenados localmente.

## Novidades

- Distribuição para Linux x64 em DEB e AppImage. Empacotamento Windows x64 e
  macOS Intel/Apple Silicon preservado para builds locais de desenvolvimento.
- Implementação multiplataforma de atualizações preservada no código; feeds e
  atualizações oficiais disponíveis somente para Linux.
- Release Linux com conferência dos artefatos e publicação após aprovação manual
  do mantenedor, sem depender de certificados Windows ou credenciais Apple.
- **Configurações → Arquivos** para escolher outra pasta de uploads, mover os
  arquivos existentes e restaurar a localização padrão. A seleção usa o diálogo
  nativo do sistema quando disponível.
- Exclusão definitiva de quadros e arquivos, incluindo limpeza dos registros
  excluídos por versões anteriores e de seus arquivos em disco.

## Correções e qualidade

- Tratamento dos caminhos do banco e dos módulos nativos por sistema e
  arquitetura, preservando a identidade e a pasta de dados do aplicativo.
- Recuperação da chave de segredos no Windows após encerramentos inesperados.
  Quando uma chave confirmada não pode ser decifrada, o aplicativo pede autorização
  antes de substituí-la; a integração com o GitHub precisa ser conectada novamente.
- Preservação do pomodoro e dos dados ao instalar atualizações explicitamente,
  inclusive com execução em segundo plano habilitada.
- Suíte E2E com Playwright contra o Electron real, API, banco, migrations e
  perfis isolados, além dos testes unitários e de instalação dos pacotes.
- Guias de instalação, assinatura, diagnóstico e validação para cada sistema.

## Instalação e atualização

No Linux, instale o pacote baixado com:

```bash
sudo apt install ./life-board_1.1.0_amd64.deb
```

O AppImage continua disponível. Não há instaladores Windows ou macOS nesta
release. A distribuição assinada dessas plataformas está suspensa devido aos
custos e à manutenção de certificados/serviços de assinatura e do programa Apple
Developer. Builds locais continuam possíveis, sem distribuição oficial.

## Limitações e cuidados

- A aprovação da release depende das verificações e dos testes reais de
  instalação e atualização descritos na documentação. A suíte E2E simula a
  entrega do update e não comprova um upgrade real de pacotes assinados.
- O DEB não cadastra um repositório APT; no Linux, continua sendo necessário um
  chaveiro desbloqueado e um agente PolicyKit para autorizar atualizações DEB.
- Credenciais cifradas ficam vinculadas ao sistema e ao usuário. Ao copiar um
  perfil para outro computador ou sistema, conecte o GitHub novamente.
- A exclusão de quadros e arquivos é definitiva. Preserve um backup antes de
  atualizar, principalmente se precisar dos itens excluídos em versões anteriores.
- Windows ARM64, Linux ARM64 e distribuição por lojas não fazem parte desta
  release.
