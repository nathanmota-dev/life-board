O Life Board 1.2.1 troca o backend em Node por um backend em Rust, que usa menos
memória. As telas e os dados continuam os mesmos. A distribuição continua sendo
Linux x64, em DEB e AppImage.

## Novidades

- A API agora é um binário em Rust (axum + SQLite), iniciado pelo próprio app.
  Em uma medição local com a janela aberta, o backend caiu de cerca de 70 MB
  para 14 MB, e o app inteiro, de cerca de 462 MB para 407 MB.
- Com **Continuar em segundo plano** ativado, fechar a janela agora libera a
  memória da interface, enquanto o app, a API e a bandeja continuam ativos. Ao
  reabrir, a tela é recarregada, e texto não salvo em formulários é perdido. Com
  um pomodoro em andamento, a janela só é ocultada, como antes.

## Correção

- As notas de versão em **Configurações → Atualizações** aparecem formatadas, em
  vez de mostrar o HTML como texto.

## Instalação e atualização

Instale o DEB baixado da release com:

```bash
sudo apt install ./life-board_1.2.1_amd64.deb
```

O AppImage também está disponível. Instalações existentes podem atualizar em
**Configurações → Atualizações**, após a publicação desta versão.

Esta versão não altera o formato dos dados do aplicativo nem adiciona migrations:
perfis existentes abrem normalmente. Windows e macOS continuam sem instaladores
oficiais.

Veja o [guia de instalação no Linux](../instalacao-linux.md).
