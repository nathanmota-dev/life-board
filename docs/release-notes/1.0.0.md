Primeira versão pública do Life Board, um painel pessoal para organizar a rotina
em um só lugar. Os dados ficam no computador.

## Funcionalidades

- Painel inicial com resumo do dia, foco e progresso.
- Tarefas, quadro de projetos, caixa de entrada e captura rápida por atalho global.
- Calendário de eventos e compromissos.
- Metas com marcos e progresso.
- Hábitos e rotinas personalizáveis, humor do dia e pensamentos.
- Pomodoro com controles na bandeja e notificações.
- Quadros de arquivos, tags e histórico de atividades.
- Issues e pull requests do GitHub para acompanhar.
- Interface em português e inglês, temas claro e escuro e cor de destaque.
- Inicialização com o sistema, execução na bandeja e verificação de atualizações
  em **Configurações → Atualizações**.

## Plataforma e instalação

Linux **x64**. Verificado no Ubuntu 22.04, 24.04 e 26.04 e no Debian 12 e 13.

```bash
sudo apt install ./life-board_1.0.0_amd64.deb
```

Também há o `life-board-1.0.0-x86_64.AppImage`, que requer FUSE. Confira os
downloads com `sha256sum -c SHA256SUMS.txt`. Instruções completas e migração de uma
instalação manual do AppImage:
https://github.com/nathanmota-dev/life-board/blob/main/docs/instalacao-linux.md

## Limitações conhecidas

- Somente Linux x64; não há pacotes ARM, Windows ou macOS.
- O DEB não cadastra um repositório APT: atualize pelo app ou instalando o pacote
  novo manualmente.
- É necessário um chaveiro do sistema desbloqueado (GNOME Keyring ou KWallet).
- Instalar atualizações do DEB pelo app exige um agente de autorização do PolicyKit
  na sessão.
